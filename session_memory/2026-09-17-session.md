## Decisions and why

1. **Agora has no delete-room feature.** Nothing in `apps/server/src` or
   `apps/web/src` deletes or archives a room — only create, set members, and
   remove one member. So this was done as direct SQL against `data/agora.db`.
   If rooms need removing again, that is the moment to build the feature rather
   than repeat hand-written SQL.
2. **The schema has no foreign keys and no cascade.** Every table holding a room
   is cleared by hand, children first: `steps` (via its goals), `goals`,
   `messages`, `mind_stones`, `agent_reads`, then `rooms`. Miss one and the row
   survives, pointing at a room that no longer exists. Run the leftover check.
3. **The crew files were kept.** `agents/erasr/` (6 bots) and
   `agents/eval/web-scout.md` stay on disk, with their `_room.md`, as retired
   crew belonging to no room. They still hold their erasr wrapper grants.
4. **`_shared/` is gone.** It existed for agents in more than one room. With Eval
   removed, all four were down to a single room, so they moved back in:
   `n0tail` → `trunks/`, `fury`, `kooyapedia-writer` and `kooyapedia-critic` →
   `erp-kooyapedia/`. An empty `_shared/` would have implied a sharing that no
   longer exists. It comes back the moment an agent joins a second room.

## Mistakes worth not repeating

(a) **`VACUUM INTO` takes a single-quoted SQL string literal.** Two failed
attempts at the backup, and the second is the nastier one:
  - `JSON.stringify(path)` produces double quotes, which SQLite reads as a
    **column name** — "no such column: /home/...".
  - Writing `'${out}'` inside a single-quoted `node -e '...'` lets the **shell**
    eat the quotes, so SQLite receives `VACUUM INTO ` and says "incomplete input".
  A quoted heredoc (`node - <<'JS'`) passes the script through untouched. Use it
  for anything with quotes in it.

(b) **A direct DB write does not reach open browser tabs.** The server only
broadcasts `rooms` when it is the one making the change, so a tab opened before
the delete still lists the old rooms until it is reloaded. Refresh before
concluding something did not work.

(c) Same trap as yesterday, still worth keeping: commands that each `cd` and run
together race on the working directory. Absolute paths.

## Open

- No delete-room path in the app. Anyone repeating this is writing SQL by hand.
- `agents/erasr/_room.md` and `agents/eval/_room.md` describe rooms that no
  longer exist. Harmless — `loadRoomRules` keys off a live room's name — but they
  will look odd to the next reader.
- The backup sits in gitignored `data/`. Decide whether to keep it or drop it
  once the removal is clearly settled.
