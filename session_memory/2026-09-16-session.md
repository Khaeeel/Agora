# Agora — session memory, 2026-09-16 (repo layout)

The roster moved from 48 flat markdown files into one folder per chatroom.
Written so the next session does not re-derive why it is shaped this way, and
does not repeat the three traps that cost time here.

---

## What the layout is now

```
agents/
  <room-slug>/
    _room.md          L2 room rules (was agents/_rules-<slug>.md)
    <id>.md           that room's crew
  _shared/            crew in more than one room
  _house-rules.md     dead stub, left where it was
```

Counts as of today: voicemail-detection 6, trunks 6, erasr 6, computer-vision 6,
project-norm 7, rag 4, erp-kooyapedia 2, eval 1, `_shared` 4 — 42 agents.

## Decisions and why

1. **`_shared/`, not copies.** fury, n0tail, kooyapedia-writer and
   kooyapedia-critic work in two rooms each. An id names exactly one file, and
   two copies of an agent drift apart silently, so they sit in `_shared/`.
2. **`dm:` rooms get no folder and make nobody shared.** A DM is one agent's
   private thread, not a second team. Without this rule oslo would have been
   exiled to `_shared/` because he has a DM with Dominic.
3. **The flat layout is still read.** `loadAgents` and `agentFilePath` walk one
   level and fall back to `agents/<id>.md`, with the folder winning, so an
   interrupted move cannot serve a stale flat copy. Nothing is written flat.
4. **Wrappers in `scripts/` deliberately did NOT move.** The full path of each
   wrapper is the grant: it is written into `allow:` in 33 agent files, into
   `protocol.ts`, `orchestrator.ts` and `HOUSE_ALLOW`, and `describeCapabilities`
   matches `scripts/([a-z0-9-]+\.sh)` — **one level deep only**, so
   `scripts/rooms/erasr-run.sh` would stop matching and the agent's "You can:"
   line would quietly lose the wrapper. Grouping them is a permission change
   wearing a cosmetic hat. Only `kk.mjs` moved, to `scripts/one-off/`.
5. **Folders are one level deep, and the guard enforces it.** `agent-edit.ts`
   previously refused any path containing a separator below `agents/`; it now
   allows `agents/<room>/<id>.md` and nothing deeper. Symlinks, paths that climb
   out, and anything but Instructions/Personality are still refused.

## Mistakes worth not repeating

(a) **`git log --follow` finds nothing until the rename is COMMITTED.** Verified
the moved files before committing, got "0 revisions" on every one, and nearly
treated a working change as a bug. A staged rename is invisible to `log`.
Re-run that verification after the commit — that is the only meaningful run.

(b) **A file move silently breaks `git show <sha>:<path>`.** `harness-eval.mjs`
reconstructs each agent's grants from history. Asking for a path that did not
exist at that commit returns empty, `grantsAt` returns null, and every turn
scores against no grants — **while the script still exits 0**. Fixed with
`--follow` + `--name-only` so each commit is read at the path it actually held.
Evidence it was real: `NoUnreachableClaim` went from `pass 0 / n/a 138` to
`pass 2 / n/a 135` once history resolved.

(c) **`agent-edit.sh log` and `undo` stop dead at a rename.** Both now pass
`--follow`. Without it the mechanics lose their own edit history: `log fury`
showed one line (the move) instead of six, and `undo` would have reported
nothing to undo for any edit made before today.

(d) **Parallel shell calls that each `cd` race on the working directory.** Two
commands failed with `touch: cannot touch 'data/...': No such file or directory`
and looked like `data/` had been deleted — the DB was fine; the cwd had moved to
`apps/web`. Use absolute paths when commands run together.

(e) **The watchdog cron kills by port every 2 minutes.** `scripts/agora-watchdog.sh`
probes `/api/state` and, on anything but 200, kills whatever owns 8787 and 5183
and relaunches. `touch data/.watchdog.start.lock` buys 180 seconds of quiet;
re-touch it during long work. It was never triggered this session.

## Verified after the move

- Live server reloaded on its own: 42 agents, 10 rooms, every file read from its
  new folder. The watcher now skips dot-dirs, so restoring a `.backup-*` no
  longer re-adds retired agents to the roster.
- `pnpm typecheck` clean on both `apps/server` and `apps/web`.
- `agent-edit.sh` reads a nested agent, reads `_room.md`, and still refuses a
  path escape, an unknown agent, an unknown room and a frontmatter section.
- `harness-eval.mjs --days 2` runs, and grant history spans the rename
  (`fury` 7 revisions back to `agents/fury.md`).
